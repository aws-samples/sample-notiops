# agent 依赖的**精确版本**(约束文件)—— 部署时实际装到的就是这里的版本。
# Exact versions of the agent's dependencies. Deploys install exactly these.
#
# 谁读它:
#   · scripts/deploy_agent.sh  → export UV_CONSTRAINT=<本文件>,agentcore CLI 打 CodeZip 时
#     跑的 `uv pip install -r pyproject.toml ...` 会自动读这个环境变量(方式 B / setup.sh);
#   · scripts/package_artifacts.sh → 发版打 agent-code.zip 时同样传给 `agentcore package`(方式 A);
#   · scripts/verify_agent_deps.py → 部署前门禁默认按这里的版本真装真 import(`--latest` 金丝雀除外)。
#
# 为什么要钉:pyproject.toml 里只有版本**范围**,CLI 又不读 uv.lock,于是每次部署都要去 PyPI
# 现场解析、重新下载 —— 本机到 PyPI 慢时,一次 agent 部署能拖到 80 分钟(2026-10-11 实测),而且
# 「客户装到哪个版本」取决于他哪天部署。钉死以后:解析 26 秒 → 0.05 秒,缓存是热的时候整个打包
# 不碰网络;上游哪天发了坏版本也打不到已发布的代码。
#
# ⚠️ 不要手改。升级版本 = 先改 pyproject.toml 的范围(如需要),再跑:
#     bash scripts/refresh_agent_constraints.sh
# 它按托管运行时的平台(linux/aarch64、Python 3.13、只要 wheel)重新解析并写回本文件,然后跑
# verify_agent_deps.py 真装真 import 一遍。范围规则与已知坏版本见 pyproject.toml 文件头和
# tests/test_agent_dep_bounds.py;本文件与范围的一致性由 tests/test_agent_constraints.py 守。
#
# 当前这组版本 = 2026-10-12 现网 agent v92 实际打进包的 185 个包(冒烟 + 真实问答都过了)。
