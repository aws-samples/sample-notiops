# cost_mcp（客户 CUR 成本 MCP server）的运行时依赖 —— **全部钉死**。
#
# 为什么是 `==` 而不是范围：本仓「依赖必钉版本」（见 docs/DEPLOYMENT.md 前置依赖一节与
# tests/test_agent_dep_bounds.py 的四条规则）。这里比 agent 那边更严 —— 全等值钉死，
# 因为构建产物要进一键发布的 sha256 清单，任何浮动都会让同一个 tag 打出不同的 zip。
#
# ⚠️ 三个直接依赖（其余 33 个都是传递依赖，列全是为了可复现）：
#     mcp / mangum / boto3
#   · `mcp<2.0` **连 import 都不行** —— 2.0 把 `FastMCP` 改名成 `MCPServer`
#     （cost_mcp/server.py 用的是新名字）。上下界都必须钉。
#   · `mangum==0.21.0` 不是随便选的：cost_mcp/lambda_handler.py 的 lifespan 手法依赖
#     mangum 用 `asyncio.get_event_loop()` + `run_until_complete` 去跑 app，从而捡到
#     handler 模块里显式 set 的那个 loop。任何换成 `asyncio.run()` 的版本都会让**每次**
#     调用变成 task-group 错误。改这个版本必须跑「同一容器连调两次」的 smoke。
#   · boto3/botocore **显式带进包里**，不吃 Lambda runtime 自带的那份 —— 与
#     scripts/build_im_layer.sh 同一口径（runtime 自带版本会随 AWS 静默升，
#     「客户装到的 = CI 装到的」是本仓的硬要求）。
#
# 目标平台（与 scripts/build_cost_layer.sh 里的 pip 参数成契约）：
#     linux/x86_64, CPython 3.14, manylinux2014
#   四个带原生扩展的包：cffi / cryptography / pydantic-core / rpds-py。
#   其中 cryptography 是 `cp311-abi3` —— **稳定 ABI，在 3.14 上能加载**，别看到 311
#   就以为错了（另外三个是实打实的 cp314）。
#
# 版本集来源：2026-09-20 用
#   pip download mcp==2.0.0 mangum==0.21.0 boto3==1.43.77 \
#     --platform manylinux2014_x86_64 --implementation cp --python-version 3.14 \
#     --only-binary=:all:
# 解出的 36 个 wheel，全部有 manylinux 轮子、无一退回源码构建。
